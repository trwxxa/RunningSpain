# Static multipage site (non‑Wix)

This is a **multi-page** static rebuild (HTML/CSS only). No Wix runtime scripts.

## Publish on GitHub Pages
1. Create a public repo (recommended: `YOURUSERNAME.github.io`)
2. Upload all files in this folder to the repo root
3. Settings → Pages → Deploy from a branch → `main` / `(root)`

## Add your images
Put images into `assets/images/` and update each page to reference them.
If you upload your original images (or your Wix media exports), I can wire them in automatically.
